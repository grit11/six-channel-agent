# V2 方证鉴别指导卡草案（按需提供给 S4，须专家审核）

**性质**：帮助 LLM 抓关键比较维度的教学提示，**不是 hard-coded IF-THEN 处方规则**；任何候选仍须回查 S3 真实来源。请勿把整份胡希恕 Skill 注入每次 Prompt，不复刻其讲课口吻或剂量内容。

候选比较常涉及：

| 关注的鉴别对 | 需优先查证的事实维度 | 经典参考 |
|---|---|---|
| 桂枝汤 / 麻黄汤 | 太阳病背景下的汗出状态、恶风/恶寒、身痛和脉象 | 第 13、35 条 |
| 大青龙汤 / 小青龙汤 | 烦躁、不汗出，或咳喘、心下水气等不同表现 | 第 38、40 条 |
| 调胃承气 / 小承气 / 大承气 | 腹满、潮热、便硬、手足汗、病程与程度 | 第 207～208 条及相关条文 |
| 小柴胡 / 大柴胡 | 少阳主症、呕逆、心下急和里实相关表现 | 第 96、103 条 |
| 四逆汤 / 通脉四逆汤 | 厥冷、下利及脉微欲绝等关联脉证 | 第 323、317 条 |
| 真武汤 / 附子汤 | 水气、小便、腹痛、身体疼痛、背恶寒等 | 第 316、304 条 |
| 白虎汤 / 白虎加人参汤 | 身热、汗出、口渴程度及津液相关表现 | 第 176、168 条 |
| 葛根汤 / 桂枝加葛根汤 | 项背强、汗出、恶风等太阳病组合 | 第 31、14 条 |
| 结胸与痞证 | 心下部位、满与痛、硬结和病程证据 | 第 149 条等 |

**不可推出**：已知患者只出现一项就可唯一决定方证，或“来源列出的阴性条件”一定代表临床禁忌。没有具体病例的相关条文时，模型必须返回不确定并要求来源检索或医生补证。

此表为研究整理的候选知识卡，具体条文解释、方证适用范围与胡希恕学派观点需医学专家复核，不作为临床处方依据。
