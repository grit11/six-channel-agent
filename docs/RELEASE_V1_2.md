# V1.2 发布说明

本次将 Console 的已有六阶段升级、通用鉴别机制与评测工具统一整理到 `六经辨证推理优化` 分支。应用和 Python 包版本统一为 `1.2.0`，运行协议为 `1.2-six-stage`，知识库保持 `1.2`。

## 内容

- 五自动节点与主图医生审核，原生 Console 六阶段进度、补证和持久化恢复。
- 紧凑模型事实/候选接口、真实 Provider usage、请求缓存及来源约束的 FPEU 方证分支。
- 完整池鉴别规则扫描，来源局部绑定，双方值复验，共同支持不伪造区分性加分。
- Benchmark48 在线消融、报告身份、续跑、标签汇总、RAGAs 和配对比较工具。
- 启动、配置、架构、目录、评测和已知限制文档按当前代码重写。

## 已知限制

1. 规则解析对口语、复杂否定与症状组合覆盖不足；“暂无明确里热口渴表现”可能被误读为口渴阳性。“汗始终出不来”“便中夹脓血”等表达尚未完整识别。
2. 经典与方证支持比例在无反证时容易达到满因子，单项支持与充分支持可能同分；来源覆盖率没有参与排名。
3. 核心因子使用六经宽候选分，同经方证共享较多分数；页面支持项含共享六经背景，不等于独立计分条件数。
4. 鉴别取最大单项支持，某一候选相对另一候选的优势不代表相对全部候选最优。单方说明及复杂条件仍不能形成完整双方比较。
5. 同分按路径 ID 稳定排序，先后没有额外医学依据。排序分不能解释为概率。
6. 原始及派生知识、研发银标仍需专家审校；当前版本未完成独立临床准确性验收。
7. 生产身份、权限、隐私、安全分诊与真实 Docker/Remote 灾备恢复另行验收；S6 指医生审核，不指这些后续工程事项。

本次发布整理未改变解析和评分机制，以上问题留待后续单独优化，没有宣称医学准确率提升。
