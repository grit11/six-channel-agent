# V2.0 重建发布说明

V2 只有一条临床 LangGraph，分为 S1 事实抽取、S2 六经定位、S3 证据检索、S4 证据比较、S5 医生审核。S2 不确定时进入澄清暂停，S5 必须由医生动作完成。

已切换：业务快照、运行任务、幂等收据和 SSE 使用 V2 DTO；RAG 候选保留检索顺序，最多五个不同方证；S4 排序只来自结构化 LLM；Console 只展示事实三值、真实来源、五阶段和审核动作。

在线模型冒烟需使用真实 Provider；RAGAS 需要单独 Judge 配置；没有专家参考时不计算临床正确率。Six-channel guidance card 的专家复核状态仍需在发布前确认。
